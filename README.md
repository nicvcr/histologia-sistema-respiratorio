## 💡 Como Usar os Módulos Interativos

### 1. Mapa Mental (`mapa_mental_sistema_respiratorio.html`)
- Abra o arquivo em qualquer navegador web moderno (Chrome, Safari, Firefox, Edge).
- Utilize os botões do cabeçalho para:
  - **Baixar PNG (1080p)**: Gera imagem rasterizada em alta resolução Full HD.
  - **Baixar PNG (4K)**: Gera imagem em ultra-resolução (3840x2160) ideal para banners ou impressão.
  - **Baixar SVG**: Baixa o código vetorial original.
  - **Guia Teórico**: Abre a gaveta lateral com o texto explicativo completo e as referências.

### 2. Perguntas para a Sala (`perguntas_interativas_respiratorio.html`)
- Desenvolvido especialmente para projeção via cabo HDMI, AirPlay ou transmissão de tela.
- **Teclas de Atalho para o Apresentador**:
  - `1` e `2`: Alterna entre as questões.
  - `G`: Revela o gabarito oficial com feedback sonoro e visual.
  - `J`: Expande / recolhe as **justificativas detalhadas** de cada alternativa ($A$ a $E$).
  - `T`: Inicia ou pausa o temporizador de 60 segundos para discussão.
  - `F`: Ativa o modo Tela Cheia / Projetar.
- **Gabarito Resumido**:
  - **Questão 1 (Transporte mucociliar)**: Alternativa **B**
  - **Questão 2 (Células caliciformes)**: Alternativa **C**
